# TechBridge Journey MVP - Escopo Final

## Fonte da Visao

A visao principal do produto esta em [PRODUCT_VISION.md](PRODUCT_VISION.md). Este documento registra apenas o escopo executavel do MVP.

## Objetivo do MVP

Provar a experiencia central do TechBridge Journey com o menor escopo possivel: uma jornada completa, uma ferramenta pratica e progresso visual como travessia.

## O Que Entra no MVP

### Jornada Completa

O MVP tera apenas uma jornada completa:

**Primeira Oportunidade**

Objetivo do usuario:

> Quero conquistar meu primeiro emprego.

Missoes:

1. Criar e-mail profissional.
2. Aprender a enviar anexos.
3. Montar meu primeiro curriculo.
4. Revisar meu curriculo.
5. Concluir minha primeira travessia.

### Diagnostico Inicial

O diagnostico do MVP tera 3 perguntas:

1. Voce ja usa e-mail?
2. Voce sabe anexar um arquivo?
3. Voce ja fez um curriculo?

O resultado nao precisa escolher entre varias jornadas. Ele apenas ajusta a mensagem inicial e destaca por onde a pessoa deve prestar mais atencao dentro da jornada Primeira Oportunidade.

### Dashboard como Travessia

O dashboard deve mostrar:

- jornada ativa;
- ponte com 5 marcos de missao;
- missao atual;
- progresso local;
- conquistas;
- habilidades trabalhadas;
- acesso ao mentor lateral simulado.

### Mentor Lateral Simulado

No MVP, o mentor nao e IA real e nao deve ser prometido como agente inteligente.

Ele sera uma experiencia simulada com:

- botoes de acao;
- respostas fixas por missao;
- tom leve, humano e encorajador;
- explicacoes simples;
- exemplos predefinidos;
- ajuda para continuar a missao.

Botoes previstos:

- Explique mais simples.
- Me dê um exemplo.
- Como isso ajuda meu objetivo?
- Resuma esta missão.
- Qual é o próximo passo?

IA real fica para evolucao futura.

### Ferramenta Pratica

O MVP tera apenas uma ferramenta pratica:

- Curriculo Guiado.

O Curriculo Guiado deve ter:

- dados basicos;
- objetivo profissional;
- formacao;
- experiencias;
- habilidades;
- previa ao vivo;
- texto final copiavel.

### Progresso Local

Salvar no navegador:

- respostas do diagnostico;
- missao atual;
- missoes concluidas;
- conquistas;
- rascunho do curriculo.

## Futuro v1.1

Depois do MVP, considerar:

- jornada Autonomia Digital;
- jornada Escudo Digital;
- gerador de mensagem de candidatura;
- checklist de seguranca;
- novas missoes;
- mais variacoes de resposta do mentor.

## Criterios de Aceite do MVP

O MVP sera considerado pronto quando:

1. O usuario concluir o fluxo entrada -> diagnostico de 3 perguntas -> dashboard da jornada Primeira Oportunidade.
2. O usuario concluir pelo menos uma missao e ver a ponte/progresso avancar.
3. O usuario usar o mentor lateral simulado por botoes com respostas fixas da missao.
4. O usuario criar um curriculo basico no Curriculo Guiado e copiar o resultado.

## Riscos de Escopo

- Reintroduzir mais jornadas antes da primeira estar boa.
- Prometer mentor inteligente no MVP.
- Adicionar mensagem de candidatura antes do curriculo funcionar bem.
- Comecar backend cedo demais.
- Fazer o produto parecer curso comum em vez de travessia guiada.
